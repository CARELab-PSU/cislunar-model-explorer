# Cislunar Model Explorer

Interactive comparison of restricted dynamical models of the Earth–Moon system (2BP, CR3BP, ER3BP, BCR4BP, HR4BP, QBC4BP, ECR4BP, BER4BP, IQHR4BP, QHR4BP) against the JPL DE421 ephemeris.

- **Model map:** where each model's acceleration error stays below a tolerance around the Moon, through 2026.
- **Trajectory generator:** click to place a spacecraft in the CR3BP frame and drag to set its velocity; the same initial state is propagated in every model and compared with an ephemeris trajectory.
- **Model hierarchy:** assumptions, equations of motion and coherence of each model.

Self-contained single page (`index.html`); all data is embedded.
